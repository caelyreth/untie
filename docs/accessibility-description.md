# Structured Accessibility Description

`display.Alt` keeps the existing `Text` and `Speech` strings and adds a
versioned semantic tree for host localization:

```go
alt := expr.Alt()

alt.Text          // compact linear notation
alt.Speech        // English spoken fallback
alt.Description   // *display.AltDescription
```

The structured form contains semantic tokens and literal content, not English
prose generated by Untie. A host can switch on the tokens and supply its own
locale, terminology, grammar, and speech conventions.

## Contract

The top level is:

```go
type AltDescription struct {
	Version int
	Root    AltNode
	Tags    []AltTag
}
```

`Version` is currently `untie.AltDescriptionVersion` (`1`). Unknown versions
must be rejected rather than guessed.

Each `AltNode` carries:

- `Kind`, a stable node discriminator;
- optional semantic roles and flags;
- `Parts` for named child positions;
- `Rows` and `Columns` for table or multiline structure;
- literal `Text` only for content-bearing leaves;
- `Code` for error nodes.

The Go fields serialize directly to JSON with stable field names. Flags and
slice ordering are deterministic for generated values. Canonical JSON is an
inspection format, not an unversioned cross-language protocol; use
`AltDescription.Version` when persisting it.

## Localization Model

Tokens are protocol identifiers. They are not localized labels. For example:

```json
{
  "kind": "fraction",
  "fractionRole": "binomial",
  "fractionStyle": "no-bar",
  "parts": [
    {"role": "numerator", "node": {"kind": "glyph", "text": "n"}},
    {"role": "denominator", "node": {"kind": "glyph", "text": "k"}}
  ]
}
```

A host can render this as its own binomial phrase. It does not need to parse
`"binomial coefficient n choose k"` out of `Alt.Speech`.

Literal payloads such as glyph text, user text, error source, and placeholder
details remain data. They are not translated by Untie. The host decides
whether a payload should be spoken verbatim, normalized, or represented by a
symbol-specific phrase.

Untie does not ship a locale database, machine translation, or fabricated
translations. The host owns language selection and linguistic policy.

## Node Coverage

Every public canonical IR node family has a corresponding description kind:

| Kind | Semantic payload |
| --- | --- |
| `row` | ordered `item` parts |
| `glyph` | literal glyph text and optional math variant |
| `text` | literal text and optional math variant |
| `operator` | literal operator text and optional math variant |
| `space` | `explicit`, `interword`, or `ignored`; semantic width for explicit spaces; optional `weak` flag |
| `fraction` | semantic role, construction style, numerator, denominator |
| `radical` | radicand and optional index |
| `scripts` | semantic role and base, top, bottom, and side-script parts |
| `fenced` | opening, content, closing; delimiter sizing; `balanced` flag |
| `sized-delimiter` | literal delimiter, math variant, sizing policy |
| `accent` | body, accent, above/below position, stretch/dotless flags |
| `line` | body and overline/underline position |
| `cancel` | cancellation/negation role, body, cross/inverted flags |
| `table` | matrix/array/cases/vector role, rows, cells, column alignment |
| `multiline` | rows and optional `centered` flag |
| `style` | body, explicit math size, cramped/uncramped state |
| `color` | body; paint is intentionally not an accessibility semantic |
| `box` | body, `fill` and `border` flags |
| `phantom` | body and preserved width/height/depth flags |
| `error` | stable error code and literal source/detail text |
| `placeholder` | literal opaque detail text |
| `break` | relation, binary, or explicit break role |
| `align-marker` | no additional payload |

Semantic roles are explicit rather than inferred from visual placement:

- `fractionRole` covers ordinary, binomial, and stacked fractions;
- `fractionStyle` preserves vertical, no-bar, skewed, and horizontal form;
- `scriptRole` covers ordinary scripts, limits, overlays, and brace labels;
- `tableRole` covers matrices, arrays, cases, and vectors;
- `cancelRole` distinguishes a strike from logical negation.

Explicit spaces expose stable semantic widths such as `thin`, `medium`,
`thick`, `en`, `quad`, `double-quad`, and their common negative forms.
Unrecognized lengths use `custom`; their exact measured length remains a
layout concern.

## Source Independence

Descriptions do not contain:

- source ranges or origins;
- `NodeID` values;
- paint or colors;
- font faces or glyph IDs;
- display geometry or line boxes;
- source dialect syntax.

Changing spans, origins, node IDs, or paint therefore cannot change the
description. A one-item `row` produced by grouping syntax is transparent in
the semantic tree, so cosmetic braces do not change localized output.

The tree can still contain semantic wrappers such as `style`, `color`, `box`,
and `phantom`. This is deliberate: hosts can decide whether a wrapper is
spoken, and all public IR families remain visible.

## Tags, Errors, and Placeholders

Formula tags are top-level `AltTag` values:

- `Body` is the tag body description;
- `Line` is `-1` for the current formula-level contract;
- `Manual`, `Starred`, and `Suppressed` preserve authored semantics;
- suppressed metadata has no body.

An `error` node carries a stable `Code` and literal `Text`. A `placeholder`
carries the IR reason as opaque `Text`. Hosts should localize the node kind and
decide how much raw detail to include. Error messages from generation failures
are English fallback text and are separate from the structured node identity.

## Cloning, Validation, and JSON

`Alt.Clone` and `AltDescription.Clone` are deep:

```go
copy := alt.Clone()
copy.Description.Root.Text = "changed" // does not affect alt
```

Use `Alt.Equal` rather than Go's `==` when comparing generated values. The
description is a pointer for compatibility, so pointer identity is not
semantic equality.

Validation checks:

- supported schema version;
- recognized node kinds, roles, flags, and part shapes;
- required parts and kind-specific fields;
- UTF-8 and NUL constraints;
- node and nesting limits;
- aggregate literal-text bytes;
- tag invariants.

```go
if err := alt.Validate(); err != nil {
	return err
}
canonical, err := alt.Description.MarshalCanonical()
```

`Alt.Speech` and `Alt.Text` remain independently validated and remain the
compatibility fallback for hosts that do not consume the structured tree.

## Limits and Cancellation

`Expr.AltContext` and `Style.GenerateAlt` generate the string and structured
forms in the same accessibility operation.

- `context.Canceled` and `context.DeadlineExceeded` return a zero `Alt`.
- Traversal, nesting, and text limits return a visible fallback plus the
  corresponding error, matching `Alt.Text`/`Alt.Speech` behavior.
- Fallback `Alt` values also carry a valid structured `error` node.
- `MaxTextBytes` bounds each compatibility string and the aggregate literal
  text payload in the structured tree.

The canonical IR node graph is traversed with cycle detection. A malformed
graph cannot recurse forever.

## MyGo

`untiemygo.DescribeFormula` exposes `FormulaSemantics.Description`. The
standalone element path can use a host callback:

```go
renderer, err := untiemygo.New(fonts, untiemygo.Options{
	LocalizeLabel: func(description *untie.AltDescription) string {
		return hostAccessibilityCatalog.Render(description)
	},
})
```

Returning an empty string falls back to `Alt.Speech`, then `Alt.Text`, then the
source. The callback is invoked on the MyGo UI thread and must not retain or
mutate the description.

The callback receives a formula-level description; it is not a locale
database. Applications can implement language selection, terminology, and
grammar in their own catalog.

## Compatibility

- Adding `Alt.Description` does not change `Alt.Speech` or `Alt.Text`.
- Nil `Description` remains valid for hand-constructed compatibility values.
- `Style.AccessibilityDisabled` and
  `untiemygo.AccessibilityDisabled` still skip accessibility traversal.
- Inline MyGo Markdown remains limited by MyGo v0.7.4's
  `markdown.InlineObject` contract and cannot receive per-object accessibility
  metadata.

See [accessibility.md](accessibility.md) for the string forms and
[stability.md](stability.md) for the public API tier.

## Intentional Coverage Limits

The schema covers every public IR node family, but it is a semantic
accessibility projection rather than a full IR serializer:

- literal glyph and operator payloads are preserved without a bundled symbol
  name dictionary; hosts map Unicode or operator text to their vocabulary;
- custom explicit-space lengths are identified as `custom` without duplicating
  their numeric layout value;
- visual-only data such as paint values, font faces, tracking, padding,
  border/rule thickness, table gaps and rules, and display geometry is omitted;
- source ranges, origins, and `NodeID` values are omitted, so description nodes
  are not source-addressable; use `Box.Hits`, `Box.Covering`, and caret stops
  for editor geometry;
- no locale catalog, translation, speech grammar, or MathML mapping is bundled;
- MyGo inline objects remain subject to the MyGo v0.7.4 accessibility metadata
  limit described above.
