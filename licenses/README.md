# Third-Party Licenses

This directory contains license texts for third-party modules used by the
released Go code.

| Module | License |
| ------ | ------- |
| `github.com/go-text/typesetting` | `Unlicense OR BSD-3-Clause` |
| `golang.org/x/image` | `BSD-3-Clause` plus Go patent grant |
| `golang.org/x/sys` | `BSD-3-Clause` |
| `golang.org/x/text` | `BSD-3-Clause` |

Upstream fixture and reference notices are kept with the fixtures under
`testdata/upstream/licenses`.
